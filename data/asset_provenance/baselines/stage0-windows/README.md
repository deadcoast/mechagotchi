# Original Stage 0 provenance baseline

These four files are exact Git blobs from commit
`19cc73d31f0781d5ab82dcdb625e76ade47d628e`, before DR 0061's correction.
They record the original Windows working-tree byte convention and native
path sorting. They are historical evidence, not a portable current ledger.

The current baseline is `data/asset_provenance/ledger.json`; its new generation
date and hash_policy identify the restatement. Every old/new digest is listed
in `data/asset_provenance/portability_restatement_stage0.json`.
