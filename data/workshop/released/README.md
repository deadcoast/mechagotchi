# Released Workshop Creatures

Creatures released from the workshop into the engine's ecosystem
simulations (T1 wire, owner DESIGN-CORRECTION 2026-07-05). Release is
strict: only engine-valid creatures land here, and evolution admits
them again through validate_grid + SLIP alignment at load. The two
founding fixtures (`released_wide_sentinel`, `released_tall_wisp`)
were authored through the workshop grid pipeline for the first wire
experiment; `mechas workshop --release <creature>` and the editor's
release action add more.
