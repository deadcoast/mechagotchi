# Vocabulary Exemplars

Creatures exercising the full grid-schema vocabulary (DR 0015 /
audit T15): dormant cell roles shell/joint/limb/antenna/
decoration/effect, materials light/signal, and organ roles
locomotion/ornament/effect. Coverage is pinned by
`labs/grid_genome/test_vocabulary_exemplars.py` so the vocabulary
cannot silently go dormant again.
