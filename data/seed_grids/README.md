# Seed Grid Corpus

This directory contains the Stage 0 hand-authored Mechagotchi seed grid corpus.

Count: 50 JSON grid genomes.

Purpose:

- Validate the first grid genome contract.
- Provide starter examples for Markov and WFC generator experiments.
- Establish readable 8x8 semantic bodies before larger grid sizes are tested.

The files were materialized from authored blueprint maps in
`labs/grid_genome/corpus_builder.py`.
