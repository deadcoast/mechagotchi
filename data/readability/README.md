# Readability Benchmark Stage 0

Held-out readability benchmark for semantic grid-genome samples.

Artifacts:

- `readability_stage0.json`
- `manual_rating_protocol.md`
- `manual_rating_template.csv`
- `manual_rating_reviewer_packet.md`
- `manual_rating_collection_gate_stage0.json`
- `manual_readability_rating_intake_stage0.json`
- `manual_rating_intake_README.md`
- `slip_readability_calibration_gate_stage0.json`
- `slip_readability_calibration_template.csv`
- `slip_readability_calibration_reviewer_packet.md`
- `slip_readability_calibration_README.md`

Human ratings have not been collected yet. The generic 30-sample template and
the SLIP long-horizon 21-sample template are included so later ratings can be
compared with the proxy metric without changing the relevant sample set.

The SLIP-specific calibration packet requires 63 completed reviewer rows
(`21 samples * 3 reviewers`) before proxy readability thresholds can be
recalibrated or used for profile-weighted evolution claims.
