JSON files deterministically, omit .bak.json backups, preserve filenames, and
show selected-file identity and preview. ,/. or arrows select; Home/End select
bounds; F5 refreshes; Enter imports the displayed selection; I/K or Escape closes
its picker without importing. F1 returns to the same selection; PgUp/PgDn and
wheel page details. No care or preparation commands execute while browsing.
Opening, selecting, paging, refresh and cancellation perform no writes or model
training. Companion time stays paused throughout and through the closing frame.
The companion remains visible. Empty/unreadable/invalid/stale input names the
problem and a recovery action. Actual keeper inbox path is available in details.

Covenant import uses the existing authority and shipped-seed compatibility gates,
then _EraBench.change_covenant for immediate persistence and conflict checks.
Only explicit Enter applies; current companion/policy and old history stay intact.
Success stays paused with its verdict until explicit return. Pack imports retain
item-level engine verdicts, display full refused-item reasons, and expose I to
choose newly staged covenants. Malformed top-level/items and invalid UTF-8 refuse
without crashing. Files changed since preview require refresh. Pack-generated
paths cannot escape the inbox or overwrite different existing bytes; repeat
identical items are already staged. Partial staging failures remain explicit
and retryable without relabelling failure as success. No registry/hosting work.
