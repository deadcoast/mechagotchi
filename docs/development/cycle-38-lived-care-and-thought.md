   the old late-life trajectory. Rank requested-horizon mean existing balance

   No IDs, labels, totals-only metadata or source hashes influence rank or seeds.
   Absent/empty context and disabled policy use the exact single old generator
   call, unchanged output/RNG. Validate malformed supplied contexts before writes.

   archive_morphology_probe_v1 using the existing calibrated lifecycle_probe_grid

   elite through the archive and continuation. Keep care out of the genome.
   Capture ordered contexts and named policy/evaluator in versioned immutable
   execution bytes. Reproduction consumes only decoded bytes; validate source,

   and parent's frozen context; newborn learning always starts cold.
