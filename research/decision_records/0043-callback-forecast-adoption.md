# Decision Record 0043: The Callback Forecast, Decided by Its Consumer — and lineage_churn Dispositioned

Date: 2026-07-21

## Status

**Accepted** (cycle 21 · Phase K · K4). The GAME's own record — the
consumer decision I3 named and refused to smuggle ("a callback-sourced
game forecast is a consumer decision"). Gates pre-registered below;
the instrument's measured values are reported from its artifact in the

## Context

I3 made the callback export path REAL: the audited upstream's pybind11
module builds in WSL, `eval_selfrep` lights `replication_per_prog`
(2 replicators of 131,072 early vs 129,211 post-takeover), and with
the channel lit the engine's own pressure math moves the multipliers
to 1.021–1.048 — real post-takeover weather IS harsher, measured
through the untouched seam. Three compact records are COMMITTED and
self-verifying (tape + soup hash + all 131,072 replication scores;
every engine number recomputed live from the committed evidence). The
game's forecast ladder stops at key 4 (`real` — the checkpoint corpus,
whose format cannot carry the replication channel). J4's structured
decoder dropped a bonus instrument: instruction density warms up
before the compression collapse — measurable from a 64-byte tape with
NO brotli, i.e., on exactly the checkpoint records whose harshness
channels are silent. And `lineage_churn` has stayed silent on every
real path, still undispositioned.

## Decisions

1. **The game adopts the callback forecast — key 5, `"callback"`**:
   `build_weather_source("callback")` returns the COMMITTED compact
   records verbatim in epoch order (the `load_real_weather_source`
   pattern exactly — search origins, and a NAMED refusal when the
   records are absent or empty; never a silent fallback). The records
   carry the lit replication channel, so the engine's own math
   produces the I3-measured harshness — zero engine-seam changes
   (DR 0021's law: the seam consumes records; the game supplies them).
2. **The J4 warm-up instrument becomes a game evidence surface**:
   `build_forecast_density_report` measures instruction density
   (the bff_noheads ten instruction bytes, mirrored from the J4 lab —
   cited, never imported across the boundary) over every committed
   forecast record's 64-byte tape, checkpoint AND callback, with the
   random expectation RECOMPUTED in-run (64 × 10/256), brotli-free by
   construction. It is an INSTRUMENT — an observation channel beside
   the forecast — and moves no multiplier; a harshness-model change
   would be its own gated record.
3. **`lineage_churn` is dispositioned BLOCKED-UPSTREAM**: the
   checkpoint format stores no lineage events, and the callback
   surface exposes none either (the committed compact records carry
   `lineage_events: []` — honest silence, not fabrication; upstream
   exposes no lineage-event stream on any surface the audited commit
   provides). The channel keeps its defensive default everywhere.
   **Re-openers, named**: an upstream lineage-event surface appearing,
   or a decision record chartering a MEASURED proxy with its own
   pre-registered gates. No proxy is smuggled here.

## Pre-registered gates (judged by the K4 pins and artifacts)

- **G1 — verbatim evidence**: the callback source is the committed
  compact records exactly (ids, order by epoch, `source_type`
  `real_cubff_python_state`); absence refuses with a named error.
- **G2 — zero engine-seam changes**: no file under `packages/`
  changes; the existing keys 1–4 tests pass UNMODIFIED.
- **G3 — the era truth**: a callback-weather era runs end to end,
  deterministic under twin construction, its provenance carrying the
  engine's own per-generation callback snapshot ids; the multipliers
  the era's engine math produces equal the I3 harshness artifact's
  committed callback values, recomputed live — self-verifying, never
  pasted.
- **G4 — the instrument is honest**: the density report's expectation
  is recomputed in-run, its byte set is the J4 lab's ten verbatim
  (mirror-cited), it imports no compression library, and it measures
  BOTH record families (the checkpoint family is the point — density
  is the harshness signal the checkpoint format CAN carry).
- **G5 — provenance visible**: the WSL-only export path stays recorded
  in the served protocol text, never hidden.
