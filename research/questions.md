# Research Questions

## Core Thesis

Can Mechagotchi become a grid-based artificial-life companion platform where
visual form, behavior, memory, mutation, survival, and SLIP profiles all
participate in one coherent evolutionary system?

## Stage 0 Questions

1. What is the minimum formal vocabulary needed to describe a companion as both
   genome and phenotype?
2. Which validation rules are hard invariants, and which are profile-specific
   preferences?
3. What data must every experiment log to be reproducible?
4. Which source categories are evidence, and which are inspiration only?

## Stage 1 Questions

1. Which primary sources should anchor grid generation, evolution, artificial
   life, micro-learning, workshop authoring, and provenance?
2. Which systems are candidates for adoption, and which must remain lab-only?
3. Which license terms require special handling before any code or assets are
   reused?

## Grid Genome Questions

1. Can one grid object represent body, renderability, mutation, animation,
   heredity, and semantic organs without becoming too heavy?
2. What is the smallest useful grid size: 8x8, 16x16, 24x24, or 32x32?
3. Can validation reject malformed creatures while preserving strange but
   legible variants?
4. Which invariants are engine-wide versus SLIP-controlled?

## Generator Questions

1. Does Markov generation beat random mutation on validity, readability,
   ancestor resemblance, and SLIP alignment?
2. Does WFC improve local visual coherence without collapsing variety?
3. Is a hybrid Markov plus validator or WFC repair path simpler than adopting
   a single generator as the core?

## Evolution Questions

1. Can MAP-Elites preserve multiple companion families instead of one dominant
   optimum?
2. Which behavior descriptors make useful archive niches?
3. Can lineage continuity be measured independently from visual novelty?

## Companion Behavior Questions

1. Can micro-learners make the companion adapt without requiring a broad neural
   model?
2. Which small models are interpretable enough for first adoption: EWMA,
   HMM-like latent mood, contextual bandits, or rule-weight learners?
3. Can the switchboard explain why it chose each action?

## Advanced Lab Questions

1. Can CUBFF dynamics become semantic traits rather than direct pixels?
2. Can CTM-inspired internal ticks improve action confidence without becoming a
   core dependency?
3. Can NCA-style growth or repair improve animation and damage recovery after
   the discrete grid core is stable?
