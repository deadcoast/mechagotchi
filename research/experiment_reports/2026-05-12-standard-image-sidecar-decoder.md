# Experiment Report: Standard Image Sidecar Decoder

Date: 2026-05-12

Status: `research_standard_image_sidecar_decoder_no_package_code`

## Question

Can Mechagotchi export a real standard image, import it through a decoder, bind
the decoded asset to a sidecar, and restore the semantic grid without inferring
organ metadata from pixels?

## Plan Alignment

This continues the Stage 7 workshop/editor track in `docs/02-research_plan.md`.
The preceding sidecar experiment proved the metadata strategy. This experiment
tests the next narrower claim: static non-interlaced 8-bit RGBA PNG
import/export for current generated `SLIP` profile grids. No `packages/` code
was created.

## External Source Refresh

The decoder is anchored to the W3C PNG specification:
https://www.w3.org/TR/png-3/

The Stage 0 implementation checks the PNG signature, IHDR, IDAT, IEND,
CRC-32 values, zlib-compressed scanlines, bit depth, color type, filter method,
and interlace method for the supported subset. It supports only static,
non-interlaced, 8-bit RGBA PNG with filter type 0.

## Method

Added `labs/workshop_editor/standard_image_sidecar_decoder.py` with:

- `render_grid_rgba_pixels`
- `encode_png_rgba`
- `decode_png_rgba`
- `export_standard_png_with_sidecar`
- `import_standard_png_with_sidecar`
- `run_standard_image_sidecar_decoder_lab`
- `write_standard_image_sidecar_decoder_artifacts`

The lab exports the first generated grid for each current valid profile to PNG,
creates a sidecar with the PNG content hash and dimensions, decodes the PNG,
validates the asset binding, restores the semantic grid from the sidecar, and
checks grid validity, `SLIP` alignment, semantic fidelity, and pixel fidelity.

Invalid probes cover a corrupt PNG signature and a sidecar hash mismatch.

## Interpretation

The standard-image path is now proven for the exact Stage 0 subset: static,
non-interlaced, 8-bit RGBA PNG generated by the lab encoder and decoded by the
lab decoder. The decoder reads real PNG bytes and rejects corrupt signatures and
sidecar hash mismatches.

This does not prove full PNG conformance, interlaced PNG, animated image
formats, spritesheets, full third-party project-format coverage, or embedded
PNG metadata writing. Semantic Mechagotchi metadata still comes from the
sidecar.

Supersession note: broader 8-bit non-interlaced PNG color/filter variant
coverage is now covered by
`research/experiment_reports/2026-05-13-png-variant-sidecar-decoder.md`.

Supersession note: fixed horizontal-strip spritesheet PNG import/export against
the same sidecar contract is now covered by
`research/experiment_reports/2026-05-12-spritesheet-sidecar-decoder.md`.

`research/experiment_reports/2026-05-13-third-party-project-decoder-boundary.md`.

`research/experiment_reports/2026-05-13-spritesheet-layout-variant-decoder.md`.
Packed rotation/trim atlas handling, runtime animation playback, full PNG
conformance, full project-format coverage, and embedded/native metadata
writers remain open.
