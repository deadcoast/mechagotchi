## Delivered behavior and scientific boundary

Tab within H opens a distinct paused WFC inspector. Space plays actual captured
events, comma/period step, brackets navigate attempts, Home/End select endpoints,
and V switches to the actual final-body animation when generation succeeds.
Tab/Escape returns to the unchanged constrained hatch candidate. N requests a
new WFC run. Help/paging pause playback. A final-body caption explicitly says
the trace cursor is retained; that image is not passed off as an earlier wave.

The inspector is read-only, session-only and unconditioned by the active
covenant. It trains the existing WFC model from the loaded seed corpus and
displays its genuine result; it does not adopt a creature, simulate a life or
write preparation/saves. A restart is labeled a fresh capture, never saved
history. O cannot start an unadvertised generator or invent missing provenance.

Current scientific correction: DR0042 superseded DR0031's evolution-default
clause. Constrained remains the default and WFC remains a distinct supported
arm. Dated F8/W3 wording describing WFC as current production/default was stale;
those reports/artifacts are retained unchanged and current docs explicitly
correct the claim. No generator default, outcome, conditioning, fitness metric,
adoption threshold, lineage interpretation or historical finding changes here.

## Observational engine contract

`generate_wfc_grid(..., trace=list)` appends detached JSON-native observations
at actual boundaries: generation and attempt starts, initial weighted wave,
sampled cell/token and original counts, applied propagation, empty proposed
contradiction, collapsed matrix, actual finishing rejection/normalization/core
retention/anchor, palette selection, success or exhaustion. A contradiction's
empty proposal was never applied to the wave; the inspector preserves that
distinction. Final pixels consume the engine packet; diagnostic pixels depict
only recorded candidate sets and actual matrix changes.

There are no observer callbacks, extra RNG draws, changed sampling/iteration,
new output metadata or relaxed failure semantics. Existing untraced calls and
returned genomes remain exact. An optional list survives errors; invalid models
can raise at their original boundary without a fabricated completion event.
Public exports remain unchanged. The package contract documents event semantics.

A foreground-owned worker captures the bounded call. UI polling and rendering
continue; the displayed event count is actual appended observations, with no
synthetic percentage. Cancellation discards the new view after the engine call
completes unchanged. Every exit joins the worker. Close waits safely, while
failed captures retain genuine events for inspection/retry.
