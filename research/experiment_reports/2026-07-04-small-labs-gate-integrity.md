# Small Labs Gate Integrity Pass

Date: 2026-07-04

Status: `research_small_labs_gate_integrity_no_package_code`

## Purpose

Fix review findings M-09, M-10, M-11, M-12, L-09, L-10, L-11, and L-13 from
`docs/03-code_review/2026-07-04-code_review.md` — gate-honesty and robustness
defects across six small labs.

## What changed

1. **M-09 (architecture)** — the runtime boundary gate's two lab-import
   "negative probes" were hardcoded `accepted=False` constants that could
   never fail. `inspect_package_lab_boundary(root)` now actually scans
   `packages/**/*.py` for `labs` imports and `sys.path` mutations pointing at
   labs; probe results derive from repo state and carry `evidence` dicts
   (`package_root_exists`, `files_scanned`, offending file lists). The
   `lab_import_negative_probe_rejected` closed state is conditional on real
   rejection. A synthetic-violation test (temp `packages/` tree with a lab
   `sys.path` mutation and import) proves the probes flip to `accepted`.
2. **M-10 (readability_benchmark)** — the calibration gate's metrics read
   `by_source[...]["count"]` unconditionally and crashed with `KeyError` when
   a source group produced zero samples; now `.get(..., 0)` with an
   empty-source unit test.
3. **M-11 (cubff_transducer)** — snapshot ingestion isolates malformed
   records: bad `.jsonl` lines and bad `.json`-list records land in
   `rejected_records` (index/line + error family) while valid records
   survive; a file is only rejected wholesale at container level or when it
   yields zero valid records. Report adds `rejected_record_count` /
   `rejected_records`.
4. **M-12 (ctm_ticks)** — `confidence_gain` now compares like with like: the
   baseline confidence is computed with the same `_clamp(0.5 + margin)`
   formula as the deliberative decision. Measured effect: none —
   `mean_confidence_gain` 0.018632 before and after, decision `prototype`
   unchanged, artifact byte-identical — because `run_switchboard` already
   used the identical formula. The review's "two scales" concern was latent,
   not active; the fix removes the cross-module formula coupling so future
   divergence cannot silently skew the gain.
5. **L-09 (cubff_transducer)** — the decision `reason` now branches on
   status; `reject_direct_mapping` no longer carries a success narrative.
6. **L-10 (package_promotion)** — registry `research_blockers` are now
   evidence-aware: blockers with artifact evidence carry `cleared_when`
   checks evaluated against the metric artifacts the gate already reads
   (e.g. `human_ratings_absent` clears when `ratings_collected` is true);
   evidence-less blockers are reported `"static": true`. New
   `research_blocker_details` per candidate; only *active* blockers affect
   gate status. Current outcomes verified identical.
7. **L-11 (lifecycle_sim)** — `survival_ticks` semantics ("counts ticks
   entered, including the tick on which death occurs") documented at the
   assignment and pinned by a death-tick unit test; arithmetic deliberately
   unchanged because downstream artifacts depend on it.
8. **L-13 (cubff_transducer)** — semantic grids are compiled once
   (`run_transducer_lab` accepts precompiled grids from `main()`); output
   verified byte-identical.

## Result

All six suites green; test counts: architecture 4→6, readability_benchmark
15→16, cubff_transducer 8→13, ctm_ticks 4→4, package_promotion 4→5,
lifecycle_sim 5→6.

Artifact deltas (all JSON validated):

- `data/architecture/mecha_engine_runtime_boundary_gate_stage0.json` — probe
  `evidence` is now a real inspection record; also catches up
  `slip_blocked_state_count` 12→15 drift from the amended slip matrix.
- `data/package_promotion/mecha_engine_package_promotion_gate_stage0.json` —
  adds `research_blocker_details`; catches up a MAP-Elites threshold
  `actual` 29→33 from the H-03 descriptor fix (still passing).
- `data/cubff_real_ingest/real_snapshot_ingest_stage0_report.json` — adds
  `rejected_record_count: 0`, `rejected_records: []`.
- `data/cubff_transducer/cubff_transducer_stage0_report.json` — the
  direct-projection baseline's error breakdown gains `cell role is unknown
  ... raw_byte` entries under the schema-aligned validator (the baseline
  grids were already invalid; validity counts and the decision are
  unchanged).
- `data/ctm_ticks/` — regenerated byte-identical.

## Decision

Gate claims now derive from inspected evidence rather than constants, and
error paths report typed, partial results instead of crashing or discarding
valid data. The M-12 outcome is a negative result worth keeping: the flagged
scale mismatch was not numerically active in current code.
