SQLite ledger, complete Workshop documents, mechagotchi_pack_v1 and engine gates.

Return stable path context plus a semantic authority revision; independently pin
source refs and target disk revisions. Writes serialize in the foreground server,
refuse stale context, preserve conflicts and retain recoverable draft/authoring bytes.

explicit conflict archives. Native care remains in the game; browser lab stays separate.

export. Import assessments keep format, conflict, covenant advisory and actual era
admission separate. Exact source receipts use content identities and exclusive
publication. Uniquely attributable submitted genomes enter the existing founders
table with actual verdicts; duplicate ordered inputs retain engine behavior and
explicitly unavailable table coverage. No causal ancestry is inferred.

Limits: no cross-process transaction across all files; per-file atomic replacement
and paired recovery are explicit. No ordered replay manifest, signing or registry.
